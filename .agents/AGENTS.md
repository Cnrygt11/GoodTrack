# Project-Scoped Rules

- React tarafında bir geliştirme veya değişiklik yapılacağı zaman **yalnızca `client-app-redesign` projesi üzerinde** işlem yapılmalı, eski `client-app` projesine dokunulmamalıdır.
- Tüm geliştirmeler spagetti koddan uzak; temiz, profesyonel, modüler ve kurumsal standartlara (Separation of Concerns, Single Responsibility, Custom Hooks kullanımı, güçlü TypeScript tipleri vb.) uygun şekilde yazılmalıdır.
